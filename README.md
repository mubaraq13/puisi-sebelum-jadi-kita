# 2 Puisi di balik satu rasa

Sebuah proyek web kreatif yang menyajikan antologi puisi digital dengan pengalaman visual yang interaktif. Proyek ini dibangun untuk mendokumentasikan karya tulis dalam format yang lebih modern dan dapat diakses oleh siapa saja melalui peramban web.

## 🌟 Fitur Utama
* **Desain Responsif:** Tampilan yang nyaman dibaca baik melalui perangkat mobile maupun desktop.
* **Antarmuka Minimalis:** Fokus pada tipografi dan konten teks agar pembaca bisa meresapi setiap bait puisi tanpa gangguan.
* **Navigasi Interaktif:** Transisi antar halaman atau bait yang halus untuk menciptakan suasana membaca yang mendalam.
* **Deployment Cepat:** Menggunakan GitHub Pages untuk hosting yang ringan dan andal.

## 🛠️ Teknologi yang Digunakan
* **Frontend:** HTML5 & CSS3 (Custom styling)
* **Interaktivitas:** JavaScript (ES6+)
* **Hosting:** [GitHub Pages](https://mubaraq13.github.io/puisi-sebelum-jadi-kita)
* **Editor:** Visual Studio Code
